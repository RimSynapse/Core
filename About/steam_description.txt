[h1]RimSynapse - Core[/h1]
[b][url=https://github.com/RimSynapse/Core/wiki]Official Wiki and Documentation[/url][/b]
[b]The foundational Large Language Model (LLM) connector and narrative intelligence engine for RimWorld.[/b]

RimSynapse Core is a powerful, asynchronous background engine that natively connects RimWorld to local Large Language Models (LLMs). It acts as the central brain of the RimSynapse ecosystem, automatically intercepting vanilla game events and orchestrating them into rich, cohesive story arcs.

[h1]🔥 New Feature: LLM Direct Action Console[/h1]
[b]Tired of memorizing complex dev console codes? Just say what you want in plain English![/b]

The LLM Direct Action Console acts as an AI-powered command center. You simply open the console, type what you want in plain English, and the Storyteller LLM acts as an active agent to compile, translate, and execute native in-game tool calls automatically in real-time.

[h2]Key Features[/h2]
[list]
[*] [b]Aura, the LLM Storyteller (0.9):[/b] with a RimSynapse storyteller selected, the AI chooses WHICH eligible incident fires - on the game's own schedule, inside your difficulty budget, with a vanilla fallback when offline. Under Cassandra, Phoebe or Randy the game is stock.
[*] [b]Storyteller Persona Engine (0.10):[/b] Aura's voice is a moddable persona def, not hardcoded - per difficulty she has a personality and hand-written prose for every beat, regenerated in-character by the LLM and falling back to the prose offline. Copy the def to build your own storyteller with no code.
[*] [b]World Events Reach the Colony (0.10):[/b] world-event sources (e.g. WorldNews) publish news the storyteller can manifest AT your colony. Additive and source-gated - with no source, the game is stock.
[*] [b]GPU/VRAM Monitoring - any GPU (0.10):[/b] measured VRAM via DXGI on NVIDIA/AMD/Intel, a consumption breakdown, an on-load advisory and an in-game dashboard - all in Core. Retires the separate NVIDIA Tool add-on.
[*] [b]Storyteller Chat (0.9):[/b] talk to Aura in a floating in-game chat window (with optional voice). The chat agent holds zero game-changing tools, and your messages never trigger events - she reads only a coarse mood signal, on her own schedule.
[*] [b]World History and Open Threads (0.9):[/b] regional events and their outcomes are recorded to a save-backed history the storyteller calls back to later.
[*] [b]Universal Backend Support:[/b] Connects natively to LM Studio, Ollama, or any OpenAI-compatible local API (e.g. OpenRouter, LocalAI) without complex setups.
[*] [b]Background Threading:[/b] Never drops a frame. All LLM requests are queued, processed, and sanitized asynchronously on separate threads.
[*] [b]Dynamic Priority Queue:[/b] Manages hundreds of requests with a Linux-style top-monitor queue, prioritizing critical events and starving obsolete prompts.
[*] [b]Auto-Discovery and Keep-Alive:[/b] Detects active models and sends keep-alive pings so your LLMs never sleep.
[*] [b]Event Tracking Ledger:[/b] Snapshots colony wealth, nutrition and colonist status when events trigger, feeding the AI narrative context.
[*] [b]Faction Perception Tracking:[/b] Factions dynamically adjust their subjective perception of your wealth and strength through visits and trade.
[*] [b]Memory Infrastructure:[/b] The per-pawn memory bank, weighted tags and decay engine companion mods use to give colonists evolving memories.
[*] [b]Opportunistic Task Scheduling:[/b] Feeds low-priority requests (backstory, memory creation) into idle GPU cycles without impacting performance.
[/list]

[h2]Changelog (v0.10.0) - The Storyteller Persona and One-Mod GPU/VRAM[/h2]
[list]
[*] NEW - Storyteller Persona Engine: Aura's voice is now a moddable persona def. Per difficulty she carries a personality and hand-written prose for every beat (kickoff, positive/negative resolution, callback, idle), regenerated in-character by the LLM with the prose as the offline fallback. Callbacks reference real world-history threads, never invented ones. Copy the def to ship your own storyteller with no code.
[*] NEW - Custom-difficulty commentary: on Custom, Aura notices notable slider choices (disabled adversaries, cranked or slashed threats, softened penalties) and needles you for them.
[*] NEW - World events reach the colony: external sources (e.g. WorldNews) publish world events the storyteller can manifest AT your colony. Purely additive and source-gated - with no source installed, the storyteller is exactly stock.
[*] NEW - GPU/VRAM monitoring is built into Core for ANY GPU (NVIDIA, AMD, Intel): measured VRAM via DXGI, a consumption breakdown, an on-load advisory, and an in-game dashboard. This absorbs the separate NVIDIA Tool add-on, which is now retired - you can unsubscribe from it.
[*] NEW - Memory maintenance: relevance-weighted recall, near-duplicate coalescing on ingest, and automatic nightly/periodic compaction so long games keep their memory banks lean.
[*] NEW - Open-ended leadership / reports-to hierarchy hook for companion mods, and a MayConverse participation predicate so every mod agrees on who may take part in colony conversations.
[*] IMPROVED - Deferred-news locality gate: only off-world news is ever delayed; colony-local letters (local disease, research done, births, mental states) always show immediately.
[*] CHANGED - Vanilla letter interception retired in favour of the additive, outbound world-event model above; the LLM storyteller now chooses from the full event pool across all categories.
[/list]

[h2]Requirements and Setup[/h2]
[list]
[*] Harmony
[*] A local LLM server (like LM Studio or Ollama). We recommend 8B+ parameter models.
[*] [b]IMPORTANT: Reasoning Models (DeepSeek-R1, Gemma-QAT, etc.):[/b] These models generate internal "chain-of-thought" (reasoning) tokens before outputting the final response. This can add significant latency (30-40 seconds per request) on local setups.
[list]
[*] [b]To disable thinking in LM Studio:[/b] Go to the "My Models" tab, select your active model, and in the right-hand "Inference Settings" panel, toggle "Enable Thinking" to OFF.
[*] [b]To disable thinking in Ollama and vLLM:[/b] Check the "Disable thinking/reasoning" option under RimSynapse Core settings in-game.
[*] For the fastest, instant responses (2-3 seconds), we recommend using standard non-reasoning "Instruct" models (such as gemma-2-9b-it or llama-3-8b-instruct).
[/list]
[/list]
